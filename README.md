## レーザー加工（MDF 3 mm）

- 全29枚を **300×225 mmのMDF 4枚** に割り付けたファイルが `sheet1_300x225.svg`〜`sheet4_300x225.svg` です。青い点線は板の外形の目安で、切りません。
- **赤い線 = カット**、**黒い塗り = 彫刻**。SVGの単位はmmです。
- 外装は先に黒く塗ってから彫刻すると、彫った部分だけ木の色が出ます。
- 組み継ぎの凸凹は付けていません。板の端どうしを木工用接着剤で突き付けて組む寸法です。
- 中棚（09_shelf）は、図の下側が正面です。
- 内箱・じょうご・引き出しの内側（お菓子が触れる面）には、食品対応のコーティングか食品用シートを。
- じょうごの4枚は斜めに合わさるので、すき間は接着剤やシーリングでふさぐ。

## 配線（ESP32-C3 SuperMini）

| 部品 | 接続 |
| --- | --- |
| RC522 | SCK→GPIO4、MISO→GPIO5、MOSI→GPIO6、SDA→GPIO7、RST→GPIO10、3.3V、GND |
| 赤外線受信 HX1838B | DO→GPIO2、**3.3V**、GND |
| パッシブブザー | S→150Ω→GPIO3、−→GND |
| 障害物検知モジュール | OUT→GPIO9、＋→3.3V、GND、ENはジャンパーのまま |
| ULN2003 | IN1〜IN4→GPIO0、1、20、21、＋→5V、−→GND |
| スリットのLED（RGB/3色モジュール） | −→GND、光らせる色→220Ω→5V |
| 470µF | ULN2003の＋と−のあいだ（＋側を5Vへ） |
| 10µF | RC522の3.3VとGNDのあいだ（＋側を3.3Vへ） |

- 障害物センサーの反応距離は、基板の半固定抵抗で3 cm程度に調整します。
- GPIO9は起動時にLOWだと書き込みモードになるので、筒が空の状態で電源を入れてください。

## コードの準備

1. Arduino IDEのライブラリマネージャで **MFRC522** と **IRremote（4.x）** を入れる
2. ボードは **ESP32C3 Dev Module**、**USB CDC On Boot = Enabled**
3. コード冒頭の `WIFI_SSID` と `WIFI_PASS` を自宅のWi-Fiに書き換える（日付を取るためだけに使う）
4. 書き込み後、リモコンの「#」→カードで、使うカードを登録する

コードはこの環境ではコンパイルまで確認できていません。エラーが出たら内容を教えてください。

## 設計スクリプトの使い方（寸法を変えたいとき）

`pip install manifold3d trimesh shapely` のあと、`設計スクリプト` フォルダで次の順に実行します。

1. `python3 v3.py` → disc.stl、base.stl（円盤と底板）
2. `python3 v14.py` → adapter.stl、sensor_tube.stl、組み立て済みモデル（3Dモデル.htmlの中身は `npm i three esbuild` のうえで v14.js をバンドル）
3. `python3 make_svg.py` → レーザー加工用SVG

寸法は各スクリプト冒頭の数値（W, DI, SH, CH, TOP など）で変えられます。
