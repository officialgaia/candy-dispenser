## レーザー加工（MDF 3 mm）

- 全29枚を **300×225 mmのMDF 4枚** に割り付けたファイルが `sheet1_300x225.svg`〜`sheet4_300x225.svg` です。青い点線は板の外形の目安で、切りません。
- **赤い線 = カット**、**黒い塗り = 彫刻**。SVGの単位はmmです。
- 外装は先に黒く塗ってから彫刻すると、彫った部分だけ木の色が出ます。
- 組み継ぎの凸凹は付けていません。板の端どうしを木工用接着剤で突き付けて組む寸法です。
- 中棚（09_shelf）は、図の下側が正面です。
- 内箱・じょうご・引き出しの内側（お菓子が触れる面）には、食品対応のコーティングか食品用シートを。
- じょうごの4枚は斜めに合わさるので、すき間は接着剤やシーリングでふさぐ。

## 3Dプリント

| ファイル | 大きさ | メモ |
| --- | --- | --- |
| disc.stl | Φ80 × 16 mm（穴Φ24×4個、厚さ14） | 1穴＝1杯＝M&M約5粒。D形の軸穴がきつければヤスリで調整 |
| base.stl | Φ102 × 21 mm | 裏にモーターをM3ネジ2本で固定。中棚へはM3ネジ3本 |
| adapter.stl | Φ91 × 15 mm | 底板の壁の上に、ピン3本で位置を合わせて載せる |
| sensor_tube.stl | 78 × 35 × 16 mm（内径Φ28） | 中棚の裏にM3ネジ2本で固定。台にセンサーを載せ、窓から筒の中を見る |

RC522は前板の裏に貼ります。基板の裏側（じょうご側）の空きは上端で約7mmしかないので、ピンヘッダはL字を使うか、線を直接はんだ付けしてください。

円盤の穴（Φ24・深さ14mm、約6.3cm³）は、ミルクチョコのM&M（直径12〜13.5mm）が約5粒入る大きさです。粒の大きさや入り方で1杯4〜6粒ほどばらつきます。ピーナッツ入りなど大きい種類を使う場合は寸法の見直しが必要です。

## 固定方法（中身と箱のとめ方）

ネジでとめる3Dプリント部品と、接着するMDF板に分かれます。中の部品が宙に浮かないよう、内箱は外壁の内側いっぱい（外寸111.4×132mm）にしてあり、4面とも外壁に接着します。

| 部品 | とめ方 |
|---|---|
| モーター → base | M3ネジ2本（裏側から） |
| base → 中棚 | M3ネジ3本 |
| sensor_tube → 中棚の裏 | M3ネジ2本 |
| adapter → base | 壁の上にピン3本で位置合わせして載せるだけ（はずせる） |
| disc → モーター軸 | D形の軸穴に差し込むだけ |
| 外壁・中棚・底板・レール | 木工用ボンドで接着 |
| 内箱（4枚） | 前後板の間に左右板をはさんで箱にし、4面とも外壁の内側に接着（高さ150〜168mm、上の斜め板より下） |
| じょうご（4枚） | 上端を内箱の内側に接着、下の口はadapterの縁に載る。合わせ目は接着剤やシーリングでふさぐ |
| 基板類（ESP32・ULN2003・センサー） | 両面テープかホットボンド |
| RC522・IR受光部 | 前板の裏に両面テープかホットボンド |

組み立て順：中棚にbase・モーター・sensor_tubeをネジどめ → 底板・背面・側面と中棚を接着 → adapterとdiscを載せて動作確認 → じょうごを内箱に接着し、内箱ごと入れて外壁に接着 → 正面（RC522・IR受光部を貼ったもの） → 上の斜め板と天板。
上の斜め板と天板を付けたあとは、上の開口が内箱より小さくなるので内箱は入りません。
※円盤やadapterは、じょうごを入れたあとは上から取り出せません。軸穴の調整や動作確認は、じょうごを入れる前に済ませてください。

## 配線（ESP32-C3 SuperMini）

| 部品 | 接続 |
| --- | --- |
| RC522 | SCK→GPIO4、MISO→GPIO5、MOSI→GPIO6、SDA→GPIO7、RST→GPIO10、3.3V、GND |
| 赤外線受信 HX1838B | DO→GPIO2、**3.3V**、GND |
| パッシブブザー | S→150Ω→GPIO3、−→GND |
| 障害物検知モジュール | OUT→GPIO9、＋→3.3V、GND、ENはジャンパーのまま |
| ULN2003 | IN1〜IN4→GPIO0、1、20、21、＋→5V、−→GND |
| スリットのLED（RGB/3色モジュール） | −→GND、光らせる色→220Ω→5V |
| 470µF | ULN2003の＋と−のあいだ（＋側を5Vへ） |
| 10µF | RC522の3.3VとGNDのあいだ（＋側を3.3Vへ） |

- 障害物センサーの反応距離は、基板の半固定抵抗で3 cm程度に調整します。
- GPIO9は起動時にLOWだと書き込みモードになるので、筒が空の状態で電源を入れてください。

## コードの準備

1. Arduino IDEのライブラリマネージャで **MFRC522** と **IRremote（4.x）** を入れる
2. ボードは **ESP32C3 Dev Module**、**USB CDC On Boot = Enabled**
3. コード冒頭の `WIFI_SSID` と `WIFI_PASS` を自宅のWi-Fiに書き換える（日付を取るためだけに使う）
4. 書き込み後、リモコンの「#」→カードで、使うカードを登録する

コードはこの環境ではコンパイルまで確認できていません。エラーが出たら内容を教えてください。

## 設計スクリプトの使い方（寸法を変えたいとき）

`pip install manifold3d trimesh shapely` のあと、`設計スクリプト` フォルダで次の順に実行します。

1. `python3 v15.py` → disc.stl、base.stl、adapter.stl、sensor_tube.stl、組み立て済みモデル（3Dモデル.htmlの中身は `npm i three esbuild` のうえで v15.js をバンドル）
   回転部の寸法は v15.py の「回転部の寸法」の数値（穴の数・穴径・円盤の厚さなど）で変えられます。
2. `python3 pack.py` → レーザー加工用SVG（300×225mmの板4枚に割り付け）

寸法は各スクリプト冒頭の数値（W, DI, SH, CH, TOP など）で変えられます。
